但丁的地狱 F1 v0.6.1 原位菜单文本表修正版

用户反馈 F：游戏可加载、字体样式改变，但菜单仍是英文。F 只改了两份相同英文表中的 752，遗漏 1437；此前直接把 752 称为启动表缺乏实机依据。F1 同步修改 752 和 1437，并更新五份关联 TOC 的英文表长度，避免继续依赖这一未经确认的表归属判断。

F1 沿用 F 的字体和纹理资产，逐字节相同；不重新扩大字库，不加入新纹理。
保持 512×256 A8，原 tg4h 不变；压缩字体和纹理均原槽位写入；全部 STR 区块位置/长度、VIV 索引、资源位置与总长度保持原样。
两份英文表各替换 346 条 ID，共 692 处，包括开始、继续、选项、画面/音量/字幕/教程开关、存读档和常用提示。其他未列入的文本仍为英文。
启动字体流 2095 继续用 F 字库；另一个字体流 298 完全不动，所以进入关卡后如果切换字库，相关菜单可能仍缺字。F1 不宣称已解决关卡字库容量问题。

安装：
1. 完全退出游戏，先把 F 或其他补丁恢复为同一份原版 bigfile0.viv。不能叠加补丁。
2. 电脑安装 Python 3.9+（含 Tk），解压本包到新目录，运行 RUN_F1.bat。
3. 选择原版 bigfile0.viv，预留约 3.3 GB 输出空间。全部校验通过后才备份安装。
4. 游戏保持 English，首先检查主菜单的“开始、继续、选项”，再查看选项页。若仍英文，请提供主菜单截图；若空白，请说明空白位置。
5. 再检查进入关卡后的暂停菜单和返回主菜单，反馈字形是否缺失、大小是否正常。

恢复：退出游戏，将 F1 资源改名保留，将 .original.日期.bak 恢复为 bigfile0.viv。NRO、NSP、bigfile1 和存档均不用改。

F 的实机结果仅证明其字体加载路径可生效，不能直接证明 F1 已通过。F1 尚待实机验证。
字库与 F 相同：12px 位图、两倍几何度量、4 级透明度，仍需检查清晰度和裁切。字体许可见 Licenses。
