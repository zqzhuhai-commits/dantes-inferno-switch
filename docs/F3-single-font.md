# F3 单字库紧凑扩展

G2.1 实机可进入菜单，但开始游戏读条卡死。尚不能判断是资源重排、关卡字体更新还是运行期使用方式导致。本版按用户要求回到单字库，目的是提供可实机比较的扩展版本。

沿用 F1 的原位写入器。仅替换启动流 2095 的 minion_pro.inf/tg4d，保留原版 buttons 与关卡流 298；字体 SHOC 块位置、VIV 索引和整体长度不变。五份 TOC 中英文表长度引用仍按实际文本修正，关卡字体根长度不改。不使用双字库编码或压缩流重排。

高度/宽度排序紧凑分行排布，771 字形，图集 512×256、已用高度 233。字体压缩 9728/9860 字节，纹理 31612/39228 字节。继续保留 F1 的 12px、两倍几何大小、4 级透明度，既有 612 字形的像素及字距逐字比较。容量不仅受图集面积限制，也受 FONT 记录与 Unicode 查找页压缩大小限制；不声称这是理论极限。

每份英文表 906 个 ID，两份共 1812 处。包含 F1 346 条菜单及 F2 429 条菜单/操作说明的全部译文（其中 85 条含按键标记）。非剧情目标 1664 条，尚余 758 条。只收录完整字符集已覆盖的译文；严格核对特殊符号、占位符、按钮和换行。字幕不改。

恢复原版 bigfile0.viv，解压运行 RUN_F3.bat；不能叠加 G2.1。首先测试开始游戏与继续存档的读条，再检查教程、暂停页。关卡字体保留原版，因此游戏切换字体后可能缺字；译文写入数不等于显示验证数。

当前没有完整原版 VIV，本地验证只覆盖资产、结构模型、控制符及安装器。没有真实整包端到端生成或实机验证。

构建：`python3 packaging/build_single_font_release.py 私有样本/minion_pro.inf NotoSansSC.ttf local/Dante-F3-Single-Font-v0.6.3`。构建需要仓库固定 F1 基线 ZIP；原字体证据不公开。
